# PB10A 组装指南

PB10A · General PowerBank

> 本指南依据作者实际装配经验和当前仓库硬件资料，按先分板验证、后永久连接、最后接入电池与装壳的顺序编写。作者样机为 2025 年旧版 PCB，局部飞线已固化至最新设计。实际元件、连接点及极性以对应版本原理图、PCB、BOM 为准；电池保护板接线、结构公差及完整验收限值仍待补齐。

## 1. 整机结构

整机由主板、SW6306 电源板、面板、电池组及铝挤外壳组成。设计分工见 [硬件架构](../Hardware/Hardware_Architecture.md)。

现有装配照片：[主板与 SW6306 板](../Images/Assembly/主板与SW6306板.jpg)、[面板背面](../Images/Assembly/面板背面.jpg)、[电池组](../Images/Assembly/5S1P%20EVE%2058E.jpg)、[外壳](../Images/Assembly/外壳.jpg)。

推荐装配顺序：

```text
三块 PCB 焊接（贴片 → 直插；OLED 最后手焊）
  → 主板独立限流供电、烧录与基本功能测试
  → 临时连接 SW6306 板，验证通信（禁止 WLED）
  → 接入面板，逐块验证
  → 断电后三板永久锡焊连接
  → 接入电池组、验证充放电
  → 安装 2 mm 导热缓冲垫与绝缘
  → 装入外壳、整机验收
  → 按用户说明书完成校准
```

## 4. PCB 焊接

### 4.1 贴片与直插

1. 先焊接贴片器件（SMD），后焊接直插件及不适合回流焊的部件。检查器件方向、极性、封装及焊点，不将电芯或 OLED 随板回流。
2. 双面回流焊时，较轻、可依靠焊料表面张力保持的器件优先在第一次回流焊接；较重器件（例如 0650 封装电感）安排在第二次回流、其所在面朝上时焊接，避免第一次已焊接的大质量器件在第二次回流时因焊料重熔而脱落。具体温度曲线按锡膏和器件耐温规格设置。
3. 完成回流和必要的热风返修后，再手工焊接直插器件与 OLED；检查短路、虚焊、极性和板间焊盘，清洁并充分冷却后才进入上电流程。

### 4.2 OLED 焊接与热防护

> **重要：OLED 极不耐热，必须手工焊接。** 不得将 OLED 随板回流焊，也不要在已安装屏幕附近使用热风枪。即使热风未直接吹向屏幕，邻近区域的热风扩散、辐射及 PCB 导热也可能损坏屏幕。

优先在所有需要热风的工序完成后安装 OLED，使用合适的烙铁与短时手工焊接，避免长时间加热玻璃、排线和显示区域。如必须进行邻近热风返修，先拆下或可靠隔离 OLED，并确认其实际温度处于器件允许范围内；不能仅凭风嘴方向判断安全。

**样机经验：** 作者样机 OLED 左上角曾因焊接热影响而损坏，后续用户说明书实物图片中可清楚看到该区域。该现象属于样机装配损伤，不是正常显示效果或 UI 缺陷。见 [用户说明书的屏幕说明](User_Manual.md#12-oled-显示说明)。

## 5. 主板独立上电与烧录

### 5.1 独立供电

主板焊接完成后，先不要与 SW6306 板和面板永久连接，更不要接入电池组。断电检查供电对地、极性、短路、主要焊点和电源器件方向后，用可调限流直流电源单独为主板供电。

按当前 [主板网表](../Hardware/Preview/Netlist_主板.tel)，主板系统供电网络 VSYS 对应 H1.3，GND 对应 H1.4；实装板位号和引脚方向须与 [主板原理图 PDF](../Hardware/Preview/SCH_主板.pdf) 核对。使用与 VSYS 设计相符的电压，从受控限流条件开始，监测输入电流、3V3 电源轨及异常发热。不要把 VSYS 测试供电直接当作电池各节采样线的接线方式，不要同时接入真实电池与测试电源。

### 5.2 烧录

当前网表 H2.1 为 SWC（SWCLK），H2.2 为 SWD（SWDIO），H2.3 为 GND。接线前核对目标电压及下载器电平，不让下载器与主板供电相互反灌。固件构建见 [Firmware](../Firmware/README.md)，发布固件见 [制造文件说明](../Hardware/Manufacturing/README.md)，使用与硬件匹配的构建版本。

上电并烧录后观察 OLED 是否正常启动，有无异常复位、过流或发热。若异常，立即断电排查，不进入下一阶段。

## 6. 分板功能验证

### 6.1 主板基本功能

面板尚未装配时，可用镊子等导电工具将对应按键触点短暂接至 GND，模拟低电平有效的按键操作。先确认触点为按键信号，不接触相邻电源或其他信号焊盘。当前固件的按键映射为：

| 按键网络 | MCU 引脚 |
|---|---|
| UP | PA9 |
| DOWN | PA10 |
| LEFT | PA15 |
| RIGHT | PC6 |
| CONF | PA12 |

测试以下项目：

- OLED 显示：画面完整，检查缺行、缺列、局部热损伤及明显闪烁。
- UI 切换：通过 CONF 进入菜单，验证方向键、确认键与页面切换。**在 Powerbank 主界面不要操作会开启 WLED 的 RIGHT 键，也不要启动 SOS。** 此时不需要验证照明或高功率输出。
- I2C Scanner：进入 Settings → Sensors → I2C Scanner。按作者装配经验，完整系统正常应扫描到 7 个地址响应；主板独立运行时 SW6306 板未连接，缺少其七位地址 0x3C，因此预期为其余 6 个地址响应。其余地址及器件对应关系以 [主板原理图 PDF](../Hardware/Preview/SCH_主板.pdf) 为准，不将地址数量直接等同于物理芯片数量。0x3C 为 SW6306 的七位地址，驱动使用左移后的 0x78。若有其他缺失，检查供电、SCL/SDA 焊点及总线状态。
- 收音机：接入合适耳机/天线，确认 Radio 能启动、搜台、调频、调音量和正常播放。必要时在耳机自动模式下确认耳机插入状态。

主板测试通过后再连接 SW6306 板。

### 6.2 SW6306 板通信验证

断电后临时连接 SW6306 板所需电源、地及通信连接，核对板间焊点对应关系和极性，再通过限流直流电源上电。测试 I2C Scanner 是否新增 0x3C、SW6306 通信与初始化是否正常、Powerbank 界面能否读取有效状态。无真实电池时不把容量、保护或充放电结果当作有效整机测试；具体供电与采样条件以原理图为准。

> **严禁在面板 LED 未连接时开启 WLED 或 SOS。** LED 升压（BOOST）电路失去正常 LED 负载时可能发生过压，损坏功率级或外围器件。即使主板与 SW6306 板通信已经正常，也必须等到面板 LED 正确接入、负载连接确认无误后才可测试照明。避免误按 Powerbank 主界面的 RIGHT 键；不执行会点亮 WLED 的测试。

### 6.3 面板验证

断电后临时接入面板，核实 LED 负载、极性、按键及所有板间信号。重新限流供电，验证五键真实操作及显示界面；在确认 LED 完整连接后，从最低亮度开始验证 WLED，观察电流、异常发热及关断。三块板均通过基本验证后才进入永久连接。

## 7. 三板永久连接

先断开直流电源、下载器、USB 输入及所有其他供电，确认板上残余电压已消退。按 [装配照片](../Images/Assembly/主板与SW6306板.jpg)、面板照片及对应 PCB 对准三块板的位置，采用板间锡焊连接。

**所有设计要求连接的板间焊点均须焊接**，包括承担机械固定作用的连接点，不只焊接当前测试用到的信号点。保证对位、焊料润湿及机械强度，同时避免过量焊锡桥连、板弯曲或将热量传向 OLED。检查板间导通、短路、间距和机械稳定性，再用限流电源复核三板基本功能。具体板间位号和完整接线图待补。

## 8. 电池组接入与充放电验证

样机为 5S1P EVE 58E，见 [电池组照片](../Images/Assembly/5S1P%20EVE%2058E.jpg) 与 [硬件架构](../Hardware/Hardware_Architecture.md)。电池组需由具备相应经验的人员按电芯与保护板要求制作，确认电芯一致性、极性、各节采样线、保护板接线及绝缘。不要使用鼓包或受损电芯；不要直接对电芯壳体长时间锡焊，组内连接采用适当的电芯连接工艺。

三板永久连接并验证后，断开所有测试电源，再按原理图焊接已正确组装的电池组引出线。操作中隔离未连接的带电端子，避免工具或焊锡造成短路；具体连接顺序以保护板及电池接线要求为准，不能仅凭照片推断。确认电池保护、极性及绝缘后，才进行实际电池供电验证。

从低功率开始测试充电和放电，核对端口电压、电流、界面状态、电池电压及温升；再逐步验证主端口、Aux-A 及允许的并发模式。异常发热、过流、采样异常时停止测试。避免重复硬短路，Aux-A 短路后 INA199 损坏经验见 [测试报告](Test_Report.md#111-电源及温度保护)。

此阶段完成基本充放电能力验证后才装缓冲垫与外壳，以便直接观察电路状态和排查故障。高功率持续能力仍须按成品状态复测。

## 9. 缓冲垫与整机装壳

在电池接线及充放电基本测试完成后，按作者样机装配方式，在电池周围施加 **2 mm 导热垫**，用作缓冲及填充。确认材料电气绝缘性能、装配间隙及固定状态，避免导热垫对 OLED、板间连接或电芯施加过大压力。不能用导热垫替代必要的独立电气绝缘。

最后将三板和电池组装入铝挤外壳，检查接口与按键对位、绝缘、线缆防夹、机械固定及散热，确认壳体与带电点无意外接触。外壳实测尺寸见 [硬件架构](../Hardware/Hardware_Architecture.md#23-成品型材外壳)，完整结构件源文件与公差仍待补。

## 10. 整机验收

装壳前后均复核基本功能，装壳后重点观察结构、屏幕、按键、充放电及热表现是否受到影响。

| 检查项目 | 基本验收要求 |
|---|---|
| 机械与绝缘 | 三板连接牢固，无焊桥、松动、夹线和壳体短路风险 |
| 上电与显示 | 启动正常，OLED 无新增损伤，按键及 UI 切换正常 |
| 通信 | 完整系统 I2C 扫描符合原理图，SW6306 通信有效 |
| FM | 正常启动、调频、搜台及音量操作 |
| 电源 | 主端口和 Aux-A 基本充放电/输出正常，无异常发热或异常复位 |
| 照明 | 面板 LED 完整接入后低档启动、调光和关闭正常 |
| 休眠 | 基本休眠、唤醒与状态恢复正常 |

具体性能指标及测试工况见 [整机测试报告](Test_Report.md)，不以基本功能通过代替完整可靠性及安全测试。

**基本功能及整机验收完成后，再按照 [用户说明书：参数校准](User_Manual.md#12-参数校准) 完成时钟、传感器与测量参数的复核和校准。** 本指南不重复校准操作。
