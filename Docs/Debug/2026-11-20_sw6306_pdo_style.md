# SW6306 20V/21V PDO 电流 2A 问题与代码排版规范

日期：2026-11-20

## 现象

已使用 5A E-Marker 线缆。PB10A 充电时已可获得 **20V / 3A**
输入合同，但对外提供的 PDO/APDO 能力列表中，其他较低电压
档位显示 5A，唯独 **20V Fixed、21V PPS3、21V UFCS**
都显示 **2A**。

这是两个独立的方向：输入充电合同属于 PD **Sink**，
对外 PDO/UFCS 能力广播属于移动电源的 **Source**。

## 代码级根因和修正

在 `Firmware/BSP/SW6306/sw6306.c` 的原
`sw6306_power_current_ma()` 中存在 `high_voltage_2a`
分支：`watt >= 40` 时强制返回 2000mA（再受档位最大值限制）。
20V Fixed、21V PPS3 和 21V UFCS 的调用均传入 `1U`。
因此 `SW6306_OUTPUT_POWER_MAX=100W` 与电流宏配置 5000mA
并不能生效。

现删除该特殊上限，全部档位按整数公式统一计算：

`current_ma = floor(watt * 1000000 / voltage_mv)`

再限制到档位最大电流并**向下**取整到协议允许的步长。
在 POSET 为 100W、对应电流上限 5000mA 时：

| 输出档位 | 电压 | 编码步长 | 新广播目标 |
|---|---:|---:|---:|
| PD Fixed | 20V | 10mA | 5000mA |
| PD PPS3 | 21V | 50mA | 4750mA |
| UFCS 高压 | 21V | 50mA | 4750mA |

21V × 5000mA = 105W，超过 100W 输出功率设定，因此 21V
档位不应直接广播 5A。实际合同仍受芯片对 E-Marker、连接状态、
电池电压、温度和硬件限流的约束。

**注意**：本修正只消除了 Source 能力计算的人工 2A 限制。
输入侧 **20V / 3A** 尚未确认是否由 PD 源 PDO、电池充电
限流、SW6306 控制策略或温度导致；不能把此处修正当成
输入侧 5A 已解决。请对比 `SW6306_ReadPiMaxSet()`、
`SW6306_ReadIPortLimit()` 与 `SW6306_ReadIBattLimit()`
读回值，并结合实际 Sink 合同判断。

## 格式规范

参考 [TKWTL/3S1P-21700-Power-Bank](https://github.com/TKWTL/3S1P-21700-Power-Bank)
中的 SW6306 模块布局；对于花括号位置，采用本项目明确要求的
**K&R 同行**风格，而非原仓库的 Allman 样式。

- 缩进 4 空格，不使用 Tab，switch/case 层级保持清晰。
- 函数与控制结构的开花括号与上一行同行。
- `.clang-format` 使用 `ColumnLimit: 0`，**不因长度强制折行函数声明或调用**；
  人工分行的复杂表达式不强制合并。
- 区域之间空行隔开，复杂模块使用
  `/************************** 功能区 **************************/`
  风格的注释分割线。
- 顶层 `extern "C"` 不额外缩进；多行注释星号与起始注释对齐。
- 不格式化 CubeMX 生成代码、ST HAL、第三方 u8g2
  和生成字体/位图；见根目录 `.clang-format-ignore`。
- 本轮排版提交只更改空白、花括号的换行和注释分区，
  对已更改的源文件做去空白记号一致性检查；**尚未完成 Keil 编译**。

## 板上验收

1. 保持 100W POSET、5A E-Marker，重新上电并重新读取 Source PDO；
   查看 20V Fix 是否为 5A、21V PPS/UFCS 是否接近 4.75A。
2. 检查未使用 E-Marker 的普通 3A 线是否仍被实际协议保护
   限制为不超过 3A，而不是仅依赖寄存器目标值。
3. 分开测量 Sink 充电档位与 Source 输出档位，勿混合两者。
4. 用适当负载逐级增加输出功率，验证硬件限流与温度，
   不要直接进行 100W 长时间满负载测试。
