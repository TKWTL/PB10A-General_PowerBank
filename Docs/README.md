## 维护边界

用户可见功能、默认值与操作方式变更时同步用户说明书；硬件版本或装配工艺变更时同步组装指南。测试报告保留工况、仪器、样机和固件版本、实测值与限制，区分设计目标、配置上限与测量结果。原始测试数据按报告约定放入 `Docs/Test_Data/`（有数据时创建），展示图片引用 `Images/Testing/`。软件内部结构和历史调试过程留在 Firmware，不在产品说明书中重复。
