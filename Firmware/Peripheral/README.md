# Firmware/Peripheral · 外接芯片驱动

与 MCU 相连的功能芯片的寄存器级驱动，只做"把芯片功能翻译成函数"，不掺业务逻辑。

计划覆盖的器件（数据手册见 `相关数据手册/`）：

| 器件 | 类型 | 接口 |
|---|---|---|
| SW6306V | 多串充电宝 SoC / 协议芯片 | I2C |
| BM3451 | 电池保护前端 | — |
| INA199 | 电流检测放大器（模拟） | ADC |
| SSD1315 | 128×64 OLED 控制器 | I2C/SPI |

规则：

- 只依赖 `Core/` 与 `Drivers/`；不引用 `BSP/`、`APP/`。
- 一个器件一组 `.c/.h`，对外统一前缀（`sw6306_`、`ina199_`），内部寄存器地址/位域用枚举或宏命名，禁止裸魔数散落。
- 阻塞式延时只允许出现在初始化路径；`APP/` 可轮询的接口一律非阻塞。
- 新增模块后必须在 Keil 工程里加入 `Application/Peripheral` 分组。
