# Hardware

硬件资料：原理图、PCB、BOM、结构件与制造文件。

| 目录/文件 | 内容 |
|---|---|
| `source/` | EasyEDA Pro 工程源（`.epro2`，含原理图与 PCB） |
| `Preview/` | 主板及 SW6306 的网表、原理图 PDF、交互式 BOM |
| `Manufacturing/` | 经确认后发布的 BOM、坐标文件、Gerber、量产固件及发布说明 |
| 规划归档 | 结构件、接插件与测试点信息等，待整理后入库 |

约定：

- 二进制工程文件（`.epro2`、`.step`、`.dxf`）在 `.gitattributes` 里按 binary 处理，不做文本 diff。
- 每次打样必须留一份与固件版本对应的 tag 说明（`rev`、日期、改动点）。
- 未验证的设计不要写成“已验证”；是否已入库以实际文件为准，目前 `source/`、`Preview/`、
  `Manufacturing/` 已有对应文件，结构件与接插件资料仍待整理。
