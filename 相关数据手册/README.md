# 相关数据手册

关键器件手册与参考文档，按与工程的关联度分类。**只放只读原始文档**，不要在此目录写分析笔记（软件调试记录放 `Firmware/Debug/`，整机测试证据放 `Docs/`）。

> **版权与来源：手册版权属原厂，只用于本工程开发与远程 agent 查阅，不随对外发布分发。**
> 本目录已在版本库中；发布前必须用 `git filter-repo` 把它从历史里移除，详见
> [`../RELEASE.md`](../RELEASE.md)。目录规模已固定（24 份，约 36.6 MB），不再增长。

| 目录 | 器件 | 说明 |
|---|---|---|
| `01-MCU与参考手册/` | STM32G070CB/KB/RB 数据手册、RM0054 STM32G0x0 参考手册 | 引脚、存储器映射、外设寄存器定义 |
| `02-电源与充电/` | SW6306V（多串充电宝 SoC：数据手册、寄存器手册、EVB 原理图）、SY8368QNC、TPS54302、1040 一体成型电感、FS112/FS117/FS117B | 升降压变换、协议与充电管理；FS112 系列用途待确认 |
| `03-功率器件与电流检测/` | BSC0906NS、TPH1R403NL（N-MOSFET）、INA199（电流检测放大器） | 功率开关与电流采样 |
| `04-电池保护/` | BM3451 | 电池保护前端 |
| `05-显示模块/` | 0.96" 128×64 OLED：SSD1315 手册、I2C/SPI 原理图、模组规格书 | 人机界面屏 |
| `06-其他(非本工程)/` | BMP180、MMC5603NJ、SC7A20TR、RDA5807M、Lumileds LUXEON CX Plus CoB | 与本工程无关，暂存备用 |

约定：

- PDF 在 `.gitattributes` 中按 binary 处理，不做行尾转换与文本 diff。
- 新增器件手册时放进对应分类目录并更新本表；分类不确定时先放 `06-其他(非本工程)/`，确认后再迁移。
- 本目录原则上不再新增：确实需要新器件手册时先确认能否只引用网页链接，其次才考虑入库（会让仓库体积一次涨几 MB）。
